# Full Vue 3 Port Plan

Date: 2026-10-29. Builds on `docs/superpowers/specs/2026-10-28-settings-page-design.md` (the settings page is the pilot, already shipped in `frontend/`).

## Owner decisions (2026-10-29)

- **Redesign freely.** Behaviour must be preserved; the look may change. A consistent dark design system (CSS custom properties in `frontend/src/style.css`) replaces the Bootstrap Cyborg and old `style.css`.
- **Cut over all at once.** The old frontend (`app/frontend`) stays the default at `/` until every screen is ported. The new app is developed at `/next/` and the settings page's existing `/settings` URL keeps working. The last task switches `/` to the new app and deletes the old one.
- **Testing:** Vitest for units and components, plus Playwright run against the Docker stack for navigation, focus movement and the player handover.
- **Everything is ported,** including the player, hls.js, Chromecast and the HLS-to-MP4 handover. The Python backend does not change except for serving.

## Behaviour that must survive the redesign

Keyboard, TV remote and media-key navigation (spatial arrow-key focus, Enter/Select, Backspace = back, the `tv-ui` mode on Google/Android TV); resume position and watched tracking (localStorage plus server library sync via `/api/library*`); favorites; search history; episode targeting for TV; download/cancel flow with SSE status; HLS early playback with handover to MP4; subtitles/captions; fullscreen; Chromecast; password login page; PWA manifest and favicon; URLs `/search/:term`, `/torrent/:link/`, `/magnet/:magnet/`, `/magnet/:magnet/:filename`, `/settings`, `/` (home with History, Community Searches, Favorites, Settings shortcuts).

## Architecture

- `frontend/` stays the single Vite project: Vue 3, TypeScript, **vue-router 4** (history mode), no state library (module-level composables).
- Router base: `/next/` while both apps coexisted; since the cutover it is `/` (Vite `base` is `/`, no runtime detection).
- `src/lib/`: `storage.ts` (guarded localStorage), `magnet.ts` (hash/name parsing, file-type and episode helpers), `api.ts` (typed `get`/`post`, SSE `subscribe`, pending-request cancellation on route change), `library.ts` (watch log, progress, favorites, history, server sync), `focus.ts` (spatial navigation, key handling, TV mode).
- `src/screens/`: `HomeScreen`, `SearchResultsScreen`, `TorrentLinkScreen`, `FilelistScreen`, `DownloadScreen`, `PlayerScreen`, `SettingsScreen`; `src/components/` for shared pieces (spinner, rank mark, favorite/fullscreen/caption/chromecast buttons).
- Vendored third-party scripts (hls.js, chromecastjs, cast sender) go under `frontend/public/lib/`.
- Every ported behaviour keeps its old tests' intent; each screen gets component tests and at least one Playwright flow.

1. **Foundations.** Router and app shell, `src/lib/*` ported with unit tests, focus module, `/next/{path}` backend route (same password gate), Playwright setup and a smoke test, existing settings page mounted at `/settings`.
2. **Home** (old `search-screen`, `app.js` 2570-2884, template `index.html` 72-187): search box, billboard/poster rows, keep watching, history, community searches (trending), favorites, shortcuts.
3. **Search results** (old `search-results-screen`, `app.js` 2885-3789, template 193-338) with rank mark, spinner, grouping, TV season/episode picking.
4. **Torrent link, filelist, download** (old `app.js` 3790-4160) including cancel and SSE status.
5. **Player** (old `player` and button components, `app.js` 1200-2569, templates 400-522): hls.js, handover, captions, fullscreen, Chromecast, favorite, resume, next file.
6. **End-to-end and polish.** Playwright flows against the Docker stack (search, open, download, play with HLS, remote-key focus walk, settings), accessibility and layout pass at phone and TV widths.
7. **Cutover.** Serve the new app at `/` (SPA fallback behind the password gate, router base `/`), move `login.html`, favicon, manifest, `sw.js` into the new build, delete `app/frontend` legacy files, update Dockerfile, README and tests, remove the `/next` route. **Done**: Vite `base` is now `/`, `FRONTEND_V2_DIR` became `FRONTEND_DIR` (default `./frontend/dist`, `/frontend` in the image), `app.kodi.py` moved to `app/kodi.addon/` (still served at `/app.kodi.py`).

## Rules for every task

- Read the old code for the screen before writing; preserve behaviour, not markup. Where old behaviour is a bug, note it in the commit message rather than copying it.
- TDD for logic modules; component tests for screens; do not weaken existing backend tests.
- No new runtime dependencies beyond vue-router (and test tooling) without a reason stated in the commit.
